# Goal Weaver

Proszę o zaplanowanie i przygotowanie makiet w TypeScripcie pod implementację logiki, którą będzie robił Claude (proszę o przygotowanie pełnej dokumentacji). Aplikacja ma być prostym trackerem długofalowych celów (3 miesiące, 6 miesięcy, rok, dwa lata). Chcę mieć w nowym przed wszystkim spisane, to do czego zmierzam i chcę sobie codziennie przypominać jaki mam cel, dostawać powiadomienia na początku dnia o tym bym pamiętał jaki mam cel i pod koniec dnia, czy miniony dzień przybliżył mnie do celu. Stylistyka minimalistyczna, fancy minimal, astheatic. Na początek zaproponuj kilka kierunków
